Conocimientos fundamentales

Antes de profundizar en el mantenimiento, conoce los conceptos básicos de la computación.

Informática

Es el área que estudia el tratamiento automático de la información mediante computadoras y sistemas tecnológicos.

Computadora

Es un dispositivo electrónico capaz de recibir, procesar, almacenar y proporcionar información.

Hardware

Comprende los componentes físicos de una computadora, como el procesador, la memoria y los dispositivos periféricos.

Software

Está formado por los programas e instrucciones que permiten realizar diferentes tareas en una computadora.

Hardware y Software: dos partes fundamentales

Una computadora necesita componentes físicos y programas para funcionar correctamente.

Hardware

El hardware representa todos los componentes físicos que podemos observar y tocar en una computadora.

  • Procesador
  • Memoria RAM
  • Placa madre
  • Disco duro
  • Monitor
  • Teclado
  • Ratón

Software

El software está compuesto por los programas e instrucciones que permiten utilizar los recursos del hardware.

  • Sistema operativo
  • Navegadores
  • Aplicaciones
  • Programas de edición
  • Herramientas de diagnóstico
HardwareSoftware
NaturalezaFísica, se puede tocarLógica, no se puede tocar
EjemplosProcesador, teclado, monitorWindows, navegadores, aplicaciones
FunciónEjecuta y almacenaIndica qué hacer con los recursos

Conoce el interior de una computadora

Descubre los principales componentes internos y comprende qué función cumple cada uno.

Procesador (CPU)

Es el componente encargado de ejecutar instrucciones y realizar operaciones necesarias para el funcionamiento del sistema.

Memoria RAM

Almacena temporalmente los datos y programas que están siendo utilizados por la computadora.

Placa madre

Es la tarjeta principal que conecta los componentes y permite su comunicación.

Almacenamiento

Permite guardar archivos, programas y sistemas operativos. Entre sus principales tecnologías se encuentran HDD y SSD.

Fuente de alimentación

Proporciona energía eléctrica a los componentes internos de la computadora.

Tarjeta gráfica

Se encarga de procesar y generar imágenes que posteriormente se muestran en el monitor.

Dispositivos periféricos

Los periféricos permiten introducir información, recibir resultados y ampliar las capacidades de una computadora.

Dispositivos de entrada

Envían datos a la computadora.

  • Teclado
  • Ratón
  • Micrófono
  • Escáner
  • Cámara web

Dispositivos de salida

  • Monitor

Dispositivos de entrada y salida

Reciben y entregan información.

  • Pantalla táctil

  • Almacenamiento externo

Conoce los sistemas operativos

Los sistemas operativos administran los recursos de una computadora y permiten que el usuario interactúe con el equipo.

Windows

Microsoft

Es un sistema operativo desarrollado por Microsoft, utilizado ampliamente en computadoras personales.

Linux

Núcleo Linux

Es una familia de sistemas operativos basados en el núcleo Linux, con numerosas distribuciones.

macOS

Apple

Es el sistema operativo desarrollado por Apple para sus computadoras Mac.

¿Cómo funciona una computadora?

Una computadora realiza diferentes procesos para transformar los datos en información útil.

1

Entrada

La computadora recibe información mediante dispositivos como el teclado, ratón o micrófono.

2

Procesamiento

El procesador ejecuta instrucciones y trabaja con los datos necesarios.

3

Almacenamiento

La información puede guardarse temporalmente o de manera permanente.

4

Salida

Los resultados se presentan mediante dispositivos como el monitor, impresora o parlantes.

Diccionario básico de informática

Familiarízate con algunos términos utilizados en el mundo de la computación.

CPU

Unidad Central de Procesamiento

Ejecuta las instrucciones y realiza los cálculos del equipo.

RAM

Memoria de Acceso Aleatorio

Guarda temporalmente los datos y programas en uso.

ROM

Memoria de Solo Lectura

Conserva instrucciones permanentes que no se borran al apagar.

HDD

Unidad de disco duro

Almacena datos en discos magnéticos con partes móviles.

SSD

Unidad de estado sólido

Almacena datos en chips, sin partes móviles y con mayor rapidez.

USB

Bus Universal en Serie

Estándar de conexión para periféricos y almacenamiento.

GPU

Unidad de Procesamiento Gráfico

Procesa imágenes y video para mostrarlos en pantalla.

BIOS

Sistema Básico de Entrada y Salida

Programa inicial que prepara el hardware al encender.

S.O.

Sistema operativo

Administra los recursos y permite usar la computadora.

Periférico

Dispositivo externo

Equipo conectado que aporta entrada, salida o almacenamiento.

Hardware

Parte física

Componentes tangibles de una computadora.

Software

Parte lógica

Programas e instrucciones que ejecuta el hardware.
